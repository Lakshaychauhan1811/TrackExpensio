3 files to change. Everything explained step by step.

STEP 1 of 3 NEW FILE

Create: static/css/mobile_fix.css

On GitHub: Add file → Create new file → name it static/css/mobile_fix.css

Paste this entire CSS:

STEP 2 of 3 EDIT FILE

Edit: templates/expense_tracker.html

Find the <head> section. Find where your existing CSS is linked. Add this line RIGHT AFTER your existing CSS link:

<!-- Existing CSS (already there, don't touch) -->
<link rel="stylesheet" href="/static/css/expense_tracker.css">

<!-- ADD THIS LINE RIGHT BELOW YOUR EXISTING CSS -->
<link rel="stylesheet" href="/static/css/mobile_fix.css">
💡 Also make sure your viewport meta tag looks exactly like this (find it in <head> and update it):
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">

Now find where your navigation links are (Dashboard, AI Chat, Expenses). Wrap them in a scrollable container if not already done:

STEP 3 of 3 EDIT FILE

Edit: static/css/expense_tracker.css

Find these existing styles in your CSS and UPDATE them. Search for each one and replace:

Find and replace: logo/brand styles

.logo {
  font-size: clamp(0.9rem, 3.5vw, 1.4rem);

  max-width: 55%;
